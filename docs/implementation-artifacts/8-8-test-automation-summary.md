## 测试场景详情

### P1 - 核心功能测试 (13 个测试)

#### 导航栏显示项目展示链接
1. ✓ 侧边栏应显示"项目展示"菜单项
2. ✓ 项目展示菜单项应有正确的图标
3. ✓ 点击菜单项应跳转到 /showcase 页面
4. ✓ Header 面包屑应显示正确的路由名称

#### 菜单高亮状态
5. ✓ 在 /showcase 页面时菜单项应显示为激活状态
6. ✓ 在 /showcase/:id 详情页时菜单项应高亮
7. ✓ 在其他页面时项目展示菜单不应高亮
8. ✓ 在 /showcase/my-projects 时菜单项应高亮

#### 未登录用户访问
9. ✓ 侧边栏应显示"项目展示"菜单项
10. ✓ 点击可以正常访问公开的展示页面

#### 已登录用户访问
11. ✓ 侧边栏应显示"项目展示"菜单项
12. ✓ 点击可以访问展示页面

### P2 - 次要功能测试 (8 个测试)

#### 移动端适配
1. ✓ 移动端侧边栏应折叠为图标模式
2. ✓ 移动端"项目展示"菜单项应显示为图标
3. ✓ 移动端点击图标应正常跳转
4. ✓ 桌面端应显示图标和文字

#### 响应式断点测试
5. ✓ 在 lg 断点侧边栏应展开
6. ✓ 在小于 lg 断点侧边栏应折叠

#### 导航交互
7. ✓ 鼠标悬停应有正确的视觉反馈
8. ✓ 从展示页导航到详情页菜单应保持高亮

#### Header 路由名称测试
9. ✓ 项目详情页应显示"项目详情"标题
10. ✓ 我的项目页应显示"我的项目"标题

### P3 - 可访问性和边缘情况 (2 个测试)

1. ✓ 项目展示链接应有正确的 ARIA 属性
2. ✓ 图标尺寸应符合规范
3. ✓ 不存在的 showcase 路由也应保持菜单高亮
4. ✓ 激活状态应有正确的背景色
5. ✓ 非激活状态应有正确的文字颜色
